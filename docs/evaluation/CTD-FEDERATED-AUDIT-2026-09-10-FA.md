# ممیزی ادامه‌ی آزمایش‌های CTD و یادگیری فدرال

تاریخ ممیزی: ۱۹ شهریور ۱۴۰۵ / 2026-09-10

## نتیجه‌ی اجرایی

ویژگی‌های Conversational Temporal Dynamics در آموزش متمرکز سیگنال تشخیص افسردگی دارند. میانگین اولیه‌ی FedAvg در کمپین مرجع گمراه‌کننده بود، زیرا توزیع سه seed دوقله‌ای بود: seed 42 به AUC برابر 0.650 رسید ولی seedهای 43 و 44 به 0.353 و 0.366 فرو ریختند. آزمون برابری تک‌کلاینت نیز Central و FedAvg را تا هفت رقم یکسان بازتولید کرد؛ بنابراین حلقه‌ی فدرال سالم بود و مسئله به ناپایداری بهینه‌سازی مربوط می‌شد.

ترکیب `class_weight_mode=aggregate_counts` و `learning_rate=0.1` در آزمایش تشخیصی سه‌بذری AUCهای 0.710، 0.712 و 0.677 (میانگین 0.700) تولید کرد؛ در برابر میانگین Central برابر 0.717. پس گزاره‌ی «FedAvg سیگنال CTD را حفظ نمی‌کند» رد می‌شود. بااین‌حال این تنظیم با مشاهده‌ی Test پیدا شده و تا بازتولید در inner-CV فقط روی Train، نتیجه‌ی تأییدی محسوب نمی‌شود.

اعداد کمپین مرجع سه‌بذری (`42، 43، 44`) روی Test رسمی:

| روش | ROC-AUC میانگین | F1 میانگین | macro-F1 میانگین | PR-AUC میانگین |
|---|---:|---:|---:|---:|
| Central | 0.717 | 0.489 | 0.604 | 0.513 |
| FedAvg | 0.456 | 0.170 | 0.466 | 0.342 |
| FedAvg + DP | 0.437 | 0.151 | 0.465 | 0.335 |

این اعداد از `experiments/ctd_reference_campaign/seed_*/comparison.json` محاسبه شده‌اند، اما به‌دلیل دوقله‌ای بودن seedها نباید به‌تنهایی مبنای تشخیص معماری قرار گیرند.

## آزمایش‌های تشخیصی بعدی

| آزمایش | split | ROC-AUC میانگین | F1 میانگین | برداشت |
|---|---|---:|---:|---|
| DP، 300 round، lr=0.1، clip=0.5 | Test | 0.422 | 0.187 | بهبود پایدار ایجاد نشد |
| DP با zero initialization | Dev | 0.890 | 0.690 | سیگنال قوی روی Dev |
| DP با zero initialization | Test | 0.479 | 0.326 | انتقال به Test رخ نداد |
| DP با tail averaging | Dev | 0.867 | 0.634 | سیگنال قوی روی Dev |
| DP با tail averaging | Test | 0.445 | 0.367 | انتقال به Test رخ نداد |
| trusted-central DP diagnostic | Dev | 0.755 | 0.647 | نویز DP تنها علت شکست نیست |

منابع این جدول به‌ترتیب پوشه‌های `ctd_dp_selected_r300_lr01_c05`، `ctd_dp_zero_init_*`، `ctd_dp_tailavg_*` و `ctd_trusted_central_dp_dev` هستند.

## تفسیر و محدودیت

- شکاف بزرگ Dev/Test نشان می‌دهد تنظیم روی Dev به Test تعمیم نداده است.
- چون Test رسمی در چند آزمایش تشخیصی مشاهده شده، از این نقطه به بعد نباید برای انتخاب learning rate، initialization، clipping، تعداد round یا averaging دوباره از آن استفاده شود.
- سه seed برای توصیف پایداری اولیه مفید است، اما برای ادعای برتری و فاصله اطمینان باریک کافی نیست.
- خروجی‌های فعلی prediction سطح participant ندارند؛ بنابراین paired bootstrap میان Central و FedAvg از این artifactها قابل بازسازی نیست.
- آزمایش `ctd_zero_init_nondp_control` تک‌بذری و پس از مشاهده‌ی Test است (AUC=0.698) و فقط شاهد تشخیصی محسوب می‌شود، نه نتیجه‌ی تأییدی.

## تصمیم پیشنهادی

1. آزمون برابری تک‌کلاینت به‌عنوان شاهد سلامت حلقه ثبت شود.
2. اصلاح `aggregate_counts + lr=0.1` فقط در inner-CV روی Train بازآزمایی شود.
3. هیچ hyperparameter دیگری با Test رسمی انتخاب نشود.
4. predictionهای OOF سطح participant برای paired bootstrap ذخیره شوند.
5. تنها اگر اصلاح بدون DP تأیید شد، frozen encoder برای رفع ناپایداری بازوی DP آزموده شود.
