- راه‌اندازی پروژه، محیط Python، داده DAIC-WOZ و شبکه Hyperledger Fabric روی سرور جدید بررسی شد.
- روش‌های downsampling شامل `decimate`، `mean` و `window_functionals` به خط پردازش داده اضافه یا تکمیل شدند.
- validity masking برای کنارگذاشتن اندازه‌گیری‌های نامعتبر صوت و ویدئو اضافه شد.
- مدیریت `NaN` و `Inf` در تجمیع پنجره‌ها اصلاح شد.
- نسخه schema کش ویژگی‌ها به ۲ افزایش یافت تا کش‌های قدیمی با معنای جدید ویژگی‌ها دوباره استفاده نشوند.
- امکان انتخاب downsampling، validity، seedها و بازوهای آزمایش به اسکریپت‌های ارزیابی اضافه شد.
- خروجی predictionهای نمونه‌ای ذخیره شد تا paired participant bootstrap قابل انجام باشد.
- merge تنظیمات override در پروتکل آموزش به‌صورت nested اصلاح شد.
- اجرای فدرال همراه ledger به splitهای مشترک و داده واقعی DAIC-WOZ متصل شد.

آزمون‌های مرتبط روی محیط محلی و سرور اجرا شدند. آخرین اجرای آزمون‌های هدفمند بدون خطا بود (`30 passed` و سپس مجموعه منبع‌محور `22 passed`). بررسی lint نیز موفق بود.

## ۶. ارزیابی حملات حریم خصوصی

### Re-identification

شانس تصادفی `0.71%` بود. مرجع بدون DP:

- audio: `12.77%`
- video: `15.13%`
- text: `2.84%`

در تخصیص adaptive عملی پروژه:

- audio، epsilon برابر 2.56: موفقیت `0.71%`
- video، epsilon برابر 2.63: موفقیت `0.71%`
- text، epsilon برابر 8.81: موفقیت `0.95%`

نتیجه: ادعای کاهش re-identification برای embeddingهای منتشرشده با DP، در بودجه‌های عملی پروژه به‌وضوح تأیید شد.

### Membership inference

- مرجع بدون DP: `AUC=0.562`، advantage برابر `0.124`.
- نقاط DP از epsilon برابر 0.5 تا 512: AUC تقریباً `0.461` تا `0.464`.
- accuracy برابر 0.70 به‌علت عدم توازن کلاس‌ها شاخص مناسبی برای نتیجه‌گیری نیست.

نتیجه: سیگنال حمله با DP پایین‌تر است، اما ثابت‌بودن نتیجه در epsilonهای بسیار متفاوت، نبود dose-response و اجرای تک‌seed اجازه اثبات قطعی ادعا را نمی‌دهد. این بخش نیازمند تکرار چند-seed و بررسی توازن member/non-member است.

## ۷. پروتکل split داده

ساختار رسمی داده مورد استفاده:

- Train رسمی: ۱۰۷ شرکت‌کننده
- Dev رسمی: ۳۵ شرکت‌کننده
- Test رسمی: ۴۷ شرکت‌کننده
- مجموع: ۱۸۹ شرکت‌کننده

در پروتکل مقایسه فعلی:

- ۸۶ نفر از Train برای به‌روزرسانی وزن‌ها استفاده می‌شوند.
- ۲۱ نفر از Train برای selection، early stopping و انتخاب threshold کنار گذاشته می‌شوند.
- Dev پس از حذف شرکت‌کننده ۴۴۰ دارای ۳۴ نفر است و فقط برای report استفاده می‌شود.
- Test در این آزمایش‌های مقایسه‌ای استفاده نشده است.

این جداسازی از leakage جلوگیری می‌کند و برای مقایسه منصفانه بازوها مناسب است. پس از تثبیت کامل تنظیمات، پیشنهاد نهایی این است که مدل با کل ۱۰۷ نفر Train بازآموزی و فقط یک‌بار روی ۴۷ نفر Test ارزیابی شود.
